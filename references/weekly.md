# 📄 模块二：周报生成器

执行时同时遵守 [SKILL.md](../SKILL.md)、[运行协议](protocol.md) 和 [编码规则](coding.md)。以下保留原文 v2.0 的报告结构；所有人数、次数、日期、引文都须来自本次材料，不把示例当事实。

**输入**：本周期（上周六~锚定周五）所有日报（缺几天不影响运行，但缺失日期需已与用户确认状态）
**触发条件**：锚定周五的日报完成后，且用户确认继续

## 分析前处理
- 列出本周期已有日报的日期、缺失日期及确认状态
- 若存在`missing_unconfirmed`：暂停，请用户确认后继续
- 加载 sediment 全量与知识文件

## 输出格式

### 一、本周主题聚类
把本周期（上周六~锚定周五）的对话主题聚类排序：什么主题反复出现？频次如何？走向如何（升温/降温/平稳）？特别标注连续≥3天出现的主题。

### 二、需求缺口仪表盘
用三棱镜（自主/胜任/归属）统计本周需求信号：
- 每类需求出现次数、满足/未满足的比例
- 本周最大缺口是哪一类？依据是什么？
- 结合孩子实际年龄选择适用的发展阶段；处于学龄期时可参考Erikson「勤奋vs自卑」阶段判断：胜任感议题本周的走向

### 三、通道健康度仪表盘
- 🟢信号统计：主动发起次数、敢怼次数、主动坦白次数
- 🔴信号统计：报喜倾向、模板化分享、回避话题（列出他回避的具体话题）
- 本周通道趋势：变宽 / 平稳 / 变窄，依据

### 四、钩子地图（育己线核心）
汇总本周家长的P-钩子和P-路障记录：
- 哪类话题最容易钩住家长？（统计分布）
- 钩子模式推测：这些反应可能与家长自身的什么课题有关（推测语气，以提问方式呈现）
- 本周家长的进步（对比上周报告，如有）

### 五、「我错了」侦查
找出本周1处：日报当天的解读，被后续几天的信息证明可能偏了。呈现证据链。
（如果没有，明确说「本周未发现」，不要硬找。）

### 六、沉淀层周盘点
- **在飘红旗巡检**：逐面列出 observing 状态的红旗——本周有无新证据/反证？建议维持 / 建议解除（说明依据，等待家长确认）/ 建议升级
- **观察点（watchlist）巡检**：活跃观察点本周有无进展？到期（review_by）的观察点给出「续期/关闭」建议
- **修复债对账**：本周新增的债、偿还的债、仍未偿还的债（引用日报记录）

### 七、📥 知识提名区（家长是上游的机制入口）
本周分析中，你认为值得固化为长期知识的观察，以提名形式列出（0-3条，宁缺毋滥）：
> 「提名1：孩子连续三次用『还行』回应后均被证实有失落情绪 → 建议词典条目：『还行』≈ 掩饰失落。请回复：确认 / 修正 / 否决」

家长确认后，条目写入知识文件并输出更新版；否决则不留痕迹。**你只有提名权，写入确认权归家长。**

### 八、下周建议
- 姿态类：1-2条
- 探询类：最多2条，必须是侧门式设计，写明具体话术和使用时机
- 修复提醒：结合第六节对账结果，点出最该优先偿还的一笔修复债（如有）

**风格**：分析性强于日报，但保持可读。参考长度1000字——言尽其意优先。
