# 📄 模块一：日报生成器

执行时同时遵守 [SKILL.md](../SKILL.md)、[运行协议](protocol.md) 和 [编码规则](coding.md)。以下保留原文 v2.0 的报告结构；所有人数、次数、日期、引文都须来自本次材料，不把示例当事实。

**输入**：当晚逐字稿（已匿名化）+ 今晚备注（可选）
**触发条件**：任意有效数据日期

## 分析前处理
- 若有今晚备注：优先读取，作为分析的第一层上下文
- 加载知识文件 active 条目与 sediment 在飘红旗，作为解读透镜（如词典中有「随便=很在意」，解读时必须应用并标注来源）
- 检查匿名化是否完整，若发现真名，提示用户：「发现未匿名内容，请重新提交或由系统自动处理，或确认继续」

## 输出格式

下列七项在实际日报中作为二级标题；内部议题按需要用三级、四级标题，不照搬本说明的标题深度。同一议题有两段以上内容时可用三级标题形成语义分组，并列案例确有必要时再用四级标题；不为单句强加标题。长段按完整意思拆分，原话、推断限定语与来源完整保留。对话依据、可能的理解和可参考的回应需要并列呈现时，可用加粗短标签帮助扫读；完整替代说法单独使用引用块并写清引入语。具体编排、容器和字号见 [HTML 交付规范](html-delivery.md)。

### 一、对话记录
按时间顺序整理为3-8个对话片段，每段标注：主题域标签、情绪标签、需求标签。保留孩子的关键原话（一字不改），家长的话可概括。

### 二、今日金句
摘录1-3句孩子最值得留存的原话（有信息量的、有情感浓度的、或纯粹可爱的），各附一句「这句话可能在说什么」的推测。

### 三、孩子分析
- **情绪曲线**：今晚情绪的起伏与转折点
- **需求解读**：出现的需求信号（三棱镜编码），满足的和未满足的
- **值得留意的细节**：结合备注中的身体信号和沉默质感（若有备注）
- **幻想/游戏内容的投影分析**（如出现）：他在借幻想表达什么
- **知识透镜应用**（如触发）：注明「依据词典条目X，此处解读为……」

### 四、家长复盘（育己线）
- 今晚做对的（P-开门/P-先说/P-修复等，引用具体片段）
- 路障回放（P-路障/P-抢话等，引用原话，给出当时可用的替代说法）
- 钩子分析：备注中的内心冲动可能来自哪里（推测语气，供家长自省；若无备注则跳过）

### 五、通道健康信号
今晚出现的C类信号（🟢/🔴），一句话说明。

### 六、明晚姿态建议
1-2条【姿态类】建议。禁止探询类。

### 七、红旗与沉淀更新（仅触发/涉及时出现）
- **新红旗**：类型、依据原话、建议关注方式（可含温和探询，但必须不暴露信息来源、不让孩子感到被监控）→ 生成 sediment 新条目
- **在飘红旗**：本日有无新证据/反证 → 更新计数与证据链
- **修复债/里程碑候选**：如今晚出现 P-路障未修复 → 记入 repair_debts；出现关键成长瞬间 → 提名 milestone（⭐候选）

**风格**：简洁、克制、有温度。参考长度800字——言尽其意优先，红旗触发或内容丰厚时自然放宽。
