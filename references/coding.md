# 编码与证据规则

## 四级报告共用编码

| 维度 | 编码与含义 |
|---|---|
| 需求三棱镜 | `N-自主`（选择与决定）、`N-胜任`（能力与成就）、`N-归属`（关系与被接纳） |
| 情绪 | `E-喜`、`E-怒`、`E-哀`、`E-惧`、`E-羞`（羞耻/尴尬）、`E-嫉`、`E-平静`、`E-混合`（注明如怒+委屈） |
| 主题 | `T-学业`、`T-同伴`、`T-师生`、`T-家庭`、`T-自我`、`T-身体`、`T-幻想` |
| 家长行为 | `P-开门`（开门器/复述/命名）、`P-路障`（评判/说教/否认/敷衍表扬）、`P-抢话`、`P-钩子`（备注中未出口的冲动）、`P-修复`、`P-先说`（家长先分享的质量） |
| 绿色通道信号 | `C-主动`（主动发起或延长）、`C-敢怼`（表达对父母不满）、`C-求助`（主动说坏事/求助） |
| 红色通道信号 | `C-报喜`（只报喜倾向）、`C-模板`（标准答案式分享）、`C-回避`（转移/沉默/拒绝特定话题） |

同片段可多标签，不强塞不适用类别。不把一次平静、开心或短对话判为报喜/回避。幻想/游戏同样编码，解释只提出可能性；羞耻情绪尤其注意胜任感与尊严。

## 红旗

- `🚩身体`：被打，或身体不适反复出现。
- `🚩欺凌`：排挤、勒索、威胁迹象。
- `🚩恐惧`：对特定人或地点持续恐惧。
- `🚩自否`：自我攻击类表达独立出现累计 ≥3 次，跨日报依赖沉淀计数。
- `🚩求助`：明示或暗示需要帮助。

每项给原话/记录依据和来源，不把信号写成已证实欺凌或疾病。`C-求助` 可以是健康通道信号；是否兼属红旗取决于内容，不是见码就报警。持续与反复需要多次证据；严重单次事件可以关注，但如实写单次。更新和解除见运行协议。

## 可复核统计

- 统计单位默认一次有证据的独立信号/事件，同事件的转述或多级复述不重复算。记录日报和片段来源，供后续复查。
- 每类需求分别统计满足、未满足、无法判断。比例说明分母；未知不当未满足。多标签使各类次数之和超过片段数时注明口径。
- “连续 ≥3 天”是连续日历日都有证据，不是三个不连续的有记录日；缺日不能填补。
- 比较趋势同时报告覆盖天数/对话数，避免把资料更多误当问题加重。无前期报告不写“相比上周改善”。
- 出勤率说明计划/有效范围、已确认无对话和未知日期；缺失原因不明只给已知覆盖率或区间。没有时长/起止时间不能估算时长分布。
- 下级报告无精确计数先回查原文；拿不到就定性描述、说明统计不可恢复，不编百分比。知识应用次数以明确引用为据。
- 情绪/通道曲线可用带证据的文字或简单表格；无量表不虚构分数，不把分类信号当心理测量结果。

## 原话与转写

仅依据当前家庭提供并确认的信息处理转写错误。输出使用家长指定的代号，未指定时使用「孩子」；不保存真实姓名与代号映射，指代有歧义时先确认。

只引材料中的真实原话。其他专名用家长已有代号；匿名引文以「[同学A]」等标出替换，不保留真名映射。不凭理论润色孩子原句。

理论解释围绕片段，用推测语气。家长钩子仅来自备注或明确自述，不从一句话反推童年创伤。替代话术是“当时可用的回应”，不自动变成下次探询任务。
